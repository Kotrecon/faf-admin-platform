# Naming Convention

**Продукт:** Faf Admin Platform  
**Репозиторий:** faf-admin-platform  
**Префикс:** Faf (Firefly AI Flow platform)

## Использование названий

| Контекст        | Название           | Пример                             |
| --------------- | ------------------ | ---------------------------------- |
| Продукт         | Faf Admin Platform | "Открой Faf Admin Platform"        |
| Репозиторий     | faf-admin-platform | `git clone .../faf-admin-platform` |
| Архитектура     | Admin Platform     | "Архитектура Admin Platform"       |
| Код (namespace) | Faf.AdminPlatform  | `namespace Faf.AdminPlatform.Bff`  |
| Документация    | Faf Admin Platform | "Faf Admin Platform Documentation" |

## Бренд-гайдлайны

- **Faf** — всегда с большой буквы
- **Admin Platform** — с большой буквы в официальных материалах
- В коде можно использовать сокращения: `AdminPlatform`, `FafAdmin`
- Не использовать: "faf", "FAF", "firefly admin" (путаница)

## Слоган (опционально)

> One platform. All admin interfaces.

или

> Unified administration for Firefly AI Flow ecosystem.
